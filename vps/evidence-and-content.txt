Primary references inspected:

- OpenSSH portable servconf.c (9.6p1 and current source), inspected by audit A for trace ordering, scalar first-wins behavior, and list accumulation.

Implementation:
- enable-ssh.sh and disable-ssh.sh contain five physical lines each. Service alias rows are excluded. Active service mode is preserved; socket mode is selected for an active socket or a stopped service. Boot activation is disabled before one stop transaction containing service and socket.
- check-ssh-config.sh is a Bash entry point with embedded Python 3. OpenSSH itself evaluates configuration. Trace events provide file/line provenance; the two passes distinguish global from matched settings. Effective allow/deny values accumulate across repeated stdout lines. Command-line scalar provenance yields to matched overrides.
- install-tools.sh includes 35 apt packages, a listing mode, and a simulation mode. Installation updates indexes using APT::Update::Error-Mode=any, then installs with --no-install-recommends. All command failures propagate.
- README and one matching .md per script contain requirements, examples, and behavior details.
